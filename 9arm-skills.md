# 9arm Skills (thananon/9arm-skills)

```
/plugin marketplace add thananon/9arm-skills
```

Skills ที่ได้:

| Command | ใช้เมื่อ |
|---|---|
| `/debug-mantra` | เริ่ม debug session — reproduce → trace → falsify → cross-reference |
| `/post-mortem` | หลัง fix bug — เขียน root cause, mechanism, fix, validation |
| `/scrutinize` | review plan/PR/code — ตั้งคำถามจาก outsider perspective |
| `/management-talk` | แปลง engineer-to-engineer content เป็นภาษา VP/PM/exec |
